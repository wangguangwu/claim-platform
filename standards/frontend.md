# 前端开发规范

## 边界与组织

- 前端只能调用 Gateway 暴露的版本化 API，不得直连领域服务、数据库、消息系统或外部保司系统。
- 页面、状态与 API 客户端按业务能力组织，不按后端服务名组织；跨功能的认证、租户、错误映射和 Trace 处理必须集中管理。
- 不得在浏览器持久化外部系统明文凭证、材料原文或可跨租户复用的敏感缓存。

## 注释与署名

- 每个 Vue 页面、复用组件、Composable、Store、API 模块和导出的业务函数必须使用 JSDoc 或文件头注释，说明职责、所属功能域和关键交互约束，并包含 `@author wangguangwu`。
- 状态管理、权限控制、租户切换、错误映射和敏感信息展示逻辑必须说明业务原因；不要给显而易见的样式或简单赋值添加噪声注释。
- 注释不得包含令牌、外部凭证、真实个人信息或内部地址；过期注释视为缺陷。

## 校验

- 修改前端代码后执行与改动范围匹配的校验；准备提交前端改动时至少执行 `npm run typecheck` 与 `npm run build`。
